# Energy Aurora

Aurora Holding · Công cụ học đầu tư Buffett + săn ngọc thô ngành năng lượng Việt Nam.

## GitHub Pages

1. Settings → Pages → Deploy from branch `main` / folder `/ (root)`
2. URL: https://aurorahoulding.github.io/energy-aurora/

## Files

- `index.html` — app chính
- `assets/` — icon + nền
- `app.b64` — HTML gzip + base64

Dùng `assets/icon-512.png` hoặc `apple-touch-icon.png`.

# Energy Aurora (modular)

Aurora Holding · Học đầu tư Buffett + săn ngọc thô ngành năng lượng Việt Nam.

## Cấu trúc hiện tại

| File | Mô tả |
|------|--------|
| `index.html` | Trang chính (loader + giao diện) |
| `modules/the-rank-boc.html` | Thẻ · Rank · Bốc |
| `modules/hoc-bc-lab.html` | Học · BC · Lab · Tin |
| `modules/game.html` | Game Energy Tycoon |
| `manifest.webmanifest` | PWA |

## Cách chạy (GitHub Pages)

1. Vào **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save

**Link trang:** https://aurorahoulding.github.io/energy-aurora/

*(Có thể mất 1-2 phút để GitHub Pages cập nhật sau khi push)*

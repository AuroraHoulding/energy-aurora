# Energy Aurora

**Aurora Holding** · Học đầu tư Buffett + săn ngọc thô ngành năng lượng Việt Nam.

Phiên bản: **v5.4.24**

## Chạy trên web (GitHub Pages)

1. Repo → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` · Folder: `/ (root)`
4. Save

**URL:** https://aurorahoulding.github.io/energy-aurora/

*(Cập nhật sau 1–3 phút)*

## Cấu trúc hiện tại

| File | Mô tả |
|------|--------|
| `index.html` | Entry point (PWA + load app) |
| `Energy_Aurora_MaxCoverage 6.html` | App đầy đủ (121 thẻ, Rank, Game, Cockpit…) |
| `manifest.webmanifest` | PWA |
| `sw.js` | Service Worker offline |

## Cài như App

Mở link trên Chrome/Safari → **Thêm vào màn hình chính** / Install.
